# VoxDesk Subprocessors & Data Categories

> **Transparency & Configuration Notice**
> VoxDesk integrates with external telephony carriers, speech-to-text (STT) engines, text-to-speech (TTS) engines, Large Language Model (LLM) providers, billing processors, and CRM/calendar platforms. Only the providers explicitly configured and enabled by a tenant (or the deployment operator) receive data for that tenant's calls or messages.

## 2. Subprocessor Governance Controls

1. **Per-Agent Provider Pinning**: Tenants select the exact `stt_provider`, `llm_provider`, and `tts_provider` on each `AgentVersion` (`app/domain/agent_models.py`), preventing unapproved vendors from receiving call data.
2. **PII Redaction Prior to Post-Call & Webhook Egress**: When `RecordingPolicy.redact_pii=True`, transcripts are scrubbed by `app/gdpr/redact.py` before post-call LLM summarization (`app/telephony/post_call.py`) and before outbound webhook serialization (`app/webhooks/call_event_bridge.py`).
3. **SSRF & TLS Enforcement**: Every outbound HTTP connection to a subprocessor or tenant webhook is validated by `app/core/ssrf.py` (`require_https=True`, `follow_redirects=False`).
