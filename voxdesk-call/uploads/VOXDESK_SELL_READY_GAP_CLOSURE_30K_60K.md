## 0. NON-NEGOTIABLE RULES (apply to every PART)

**R1 — Do not skip code.** Read every file completely before editing it. In the final report output the **complete resulting content** of every created/modified file. Never write `...`, `# existing code`, `rest unchanged`, `same as before`, `omitted for brevity`.

**R2 — Preserve working logic; extend, do not duplicate.** Section 1.4 lists REAL assets. Reuse them. If a REAL module already does the job, wire to it instead of creating a parallel implementation.

**R3 — NO FAKE SUCCESS.** An endpoint, job, adapter or UI action must either perform the real external effect or return an explicit not-done state: HTTP `501`/`409` with machine code `NOT_CONFIGURED`, `UNSUPPORTED_CAPABILITY` or `PENDING_PROVIDER`. Never record `delivered`, `connected`, `success`, `200 OK` unless the real system confirmed it.

**R4 — NO FILLER, NO PADDING, NO LINE-COUNT TARGETS.** File size is an outcome, never a goal. Forbidden: generated repetitive structs/functions/endpoints (`StructN`, `*_function_N`, `/endpoint-N`), banner comments like "1050+ lines", "NO SKIP FULL CODE", "Padding … line N".

**R5 — Durable, multi-worker-safe state.** No process-local `dict`/`list` as source of truth for idempotency, rate limits, OAuth state, sessions, queues, locks. Use PostgreSQL / Redis / the existing `app/jobs` + `app/outbox`.

**R6 — Security defaults.** Every outbound URL goes through `app/core/ssrf.py`. Secrets use `app/security/secret_store.py` or `app/integrations/crm/crypto.py` (AES-GCM). Never base64/reverse/"obfuscation" as encryption. No hard-coded fallback secrets.

**R7 — Tenancy.** Every query is tenant-scoped (and environment-scoped where the model has `environment_id`). Cross-tenant access returns 404. Each new route ships a two-tenant isolation test.

**R8 — Audit & events are transactional.** Audit/outbox writes happen in the same transaction as the action. No `except Exception: pass` around audit/outbox/webhook code.

**R9 — Tests with evidence.** Every task ships: unit test + contract test. For anything that calls an external provider, add (a) a recording-fake test that asserts the real request (method, URL, headers, body) was made, and (b) an opt-in `@pytest.mark.real_provider` test (the repo's existing marker; it runs only with `VOXDESK_REAL_INTEGRATION=1` and real credentials — do NOT add a second `live` marker). A feature without a passing test is labelled `API_ONLY` or `PLANNED` in the feature manifest (never `LIVE`).

**R9b — Test layout.** Every new `tests/<dir>/` gets an `__init__.py` (repo convention); real-provider tests carry `@pytest.mark.real_provider` (already registered in `pytest.ini`), slow audio tests `@pytest.mark.slow`, stack tests `@pytest.mark.docker`; register only the new markers (`slow`, `docker`) in `pytest.ini`.

**R10 — Migrations.** As shipped there is exactly one Alembic head: `0045_request_idempotency_receipts`. Run `alembic heads` before and after; keep exactly one head; never edit an applied migration; use the next free revision number at the time you write it.

**R11 — Docs honesty.** README/docs contain only measured numbers (generated by `scripts/repo_stats.py`). Any capability without an end-to-end/contract test is documented as `API_ONLY` or `PLANNED`.

**R12 — Commit hygiene.** One commit per task ID, message `<TASK-ID>: <what changed>`. Never commit generated bulk. CI rejects null-byte files (a prior commit corrupted 755 files).

**R13 — Report format.** After each PART write `reports/PART_<n>_REPORT.md`: files changed (full content), commands run with real output, test counts (pass/fail/skip), residual gaps. Never write "production ready" without gate evidence.

**R14 — Provider versions.** `requirements.txt` pins `pipecat-ai==0.0.94` while some code comments still say 0.0.55. Before touching the voice pipeline, inspect the installed package and use only classes that exist in the pinned version; if you upgrade, do it as its own task with the full voice test suite.

**R15 — Registration & contracts.** Every new router/WebSocket is registered in `app/main.py`, has an RBAC permission, tenant scoping and an isolation test, and the OpenAPI/contract snapshot is regenerated (`make contracts-check`). New route files must not reuse the name of an existing file (check `ls app/api` first).
