Legal Agent — Clause Library, Playbook, Redline Artifacts, Versioning, Audit Chain P1-04 Fixed

LuMay: Legal playbook, clause management, redline artifacts, versioning, audit chain — demo

Clause Library — 5 Default Clauses Mapping to PATTERNS

  • ClauseLibraryEntry: key, title, category, risk_tier, version, pattern, suggested_text, fallback_text, source, review_required, fingerprint via sha256_hex
  • 5 entries: termination (PATTERN termination), limitation_of_liability (limitation_of_liability), indemnification (indemnification), confidentiality (confidentiality), data_protection (data_protection) — mapping to clause_engine.py PATTERNS
  • Versioning: version int, fingerprint sha256_hex, created_at/updated_at
  • Endpoints: GET /api/legal/clause-library?category=&q=, GET /api/legal/clause-library/{key}
  • Repository: ClauseLibraryRepository list_entries, get_by_key, get_by_id, search(category, query)

Playbook — Rules, Scope, Evaluation

  • Playbook: id, tenant_id, organization_id, environment_id, name, version, status draft/active/archived, clauses[], rules[], created_at, updated_at
  • PlaybookRule: id, clause_key, operator contains/equals/gte/lte, value, severity, action, fingerprint sha256_hex
  • 3 default rules: termination_missing (finding contains termination, severity critical, action suggest_standard_termination), liability_cap_missing (limitation_of_liability, high, suggest_liability_cap), confidentiality_duration (confidentiality, medium, suggest_confidentiality_duration)
  • Service: PlaybookService.create_playbook(tenant_id, org_id, env_id, name, clause_keys) + evaluate_against_playbook(findings, playbook) → matched evaluations with review_required
  • Endpoints: GET/POST /api/legal/playbooks?environment_id=, GET /api/legal/playbooks/{id}, POST /api/legal/playbooks/{id}/evaluate with findings[]
  • Repository: PlaybookRepository uses governance policies table type=legal_playbook — existing architecture reuse

Redline Artifacts — difflib, Fingerprint, Disclaimer, Reviewer Workflow

  • RedlineChange: change_type insertion/deletion/replacement, original_text, suggested_text, rationale, clause_key, source_reference, evidence_reference, fingerprint via sha256_hex of original+suggested+clause
  • RedlineArtifact: id, document_id, playbook_id, changes[], diff_html via difflib.HtmlDiff, fingerprint sha256_hex, disclaimer "AI-generated redline suggestion only; not legal advice. Qualified human must review.", review_state pending/approved/rejected, evidence_references[], created_at
  • Engine: RedlineEngine.generate_redline(document_id, findings[], playbook, evidence_refs) uses SequenceMatcher, _wrap_html(), _clause_to_original(), _clause_to_suggested(), generate_for_document() groups by finding
  • Endpoints: POST /api/legal/redlines with document_id, playbook_id, findings[], evidence_references[], GET /api/legal/redlines/{id}?environment_id=, POST /api/legal/redlines/export with audit package fingerprint
  • Persistence: RedlineRepository save_artifact, get_artifact, list_for_document, export_audit_package with fingerprint, exported_at, disclaimer, artifact_count

Versioning & Audit Chain — Evidence

  • ClauseLibrary versioning via version field, fingerprint
  • Playbook versioning: version int, created_at/updated_at, status draft/active/archived
  • Redline audit package: export_audit_package() with fingerprint, exported_at, disclaimer, artifact_count, artifacts[] as_dict()
  • Evidence chain: evidence_references passed to redline artifacts, linked to review cases, evidence chain payload_hash/previous_hash
  • No legal-certainty claims — all suggestions require human review, disclaimer on every artifact, review_state required
