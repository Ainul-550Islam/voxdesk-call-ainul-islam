Voice Agent Studio — Design → Voice → Connect → Launch

Production voice orchestration backed by app/voice/provider_registry.py, voice_profile_service.py, clone.py, telephony/ivr.py validate_flow(), transfer.py answer_on_bridge, and Deepgram nova-3 → nova-2 fallback.

1. Design — Call Flow, Personality & Language

  • IVR editor with 6 node types: greeting, menu, input, transfer, hangup, ai with DTMF routing.
  • validate_flow() prevents dangling edges, unreachable nodes, and dead-end menus.
  • 13 verified locales (en-US/GB/AU, es-US/MX, fr, de, pt-BR, it, nl, hi, ar, bn).
  • Dynamic variable interpolation ({customer_name}, {appointment_window}) via dynamic_variable_service.py.

2. Voice — Provider Mix, Cloning & Streaming

  • TTS providers: ElevenLabs, OpenAI, Deepgram Aura with sub-second first-audio target (550–750ms).
  • STT providers: Deepgram nova-3 with automatic nova-2 language fallback.
  • Consent-verified voice clone lifecycle: submit, processing, cancel, and worker recovery.
  • Cross-call contact memory lookup and episodic summarization per caller E.164 number.

3. Connect — Telephony, E.164 & 21 CRM/Calendar Connectors

  • Twilio & Telnyx SIP/PSTN bridging with warm transfer whisper briefing and fallback rules.
  • Strict E.164 phone number normalization and tenant-scoped number assignment.
  • Calendars: Google Calendar, Microsoft 365, Cal.com, and internal slot engine.
  • CRMs: HubSpot, Salesforce, GoHighLevel, Jobber, ServiceNow, Zendesk, and HMAC Webhooks.

4. Launch — Scenario Testing, Guardrails & Deployment

  • Automated scenario test runner with pass/fail rubric evaluation before promotion.
  • Outbound guardrails: timezone-aware calling windows (9am–8pm), centralized DNC check, and retry backoff.
  • Multi-environment promotion (Staging → Production) with immutable version snapshots.
  • Live supervisor monitoring: listen, whisper, barge, and human takeover.
