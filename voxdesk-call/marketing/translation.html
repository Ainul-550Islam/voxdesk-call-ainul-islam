Engine — Provider-Agnostic

  • Requires approved ModelVersion metadata (provider + model_name) + api_key_for() — when unavailable, raises UnsupportedFeatureError, no invented translation
  • Preserves placeholders, URLs, emails, numbers per prompt — per engine.py
  • Source/target must differ, segments required, non-text result raises AgentExecutionError
  • Fingerprints: source_fingerprint + target_fingerprint SHA256 via hashlib
  • Provider: injected provider or existing app/agent/text_agent.py path (openai, anthropic, google)

Glossary — Version Control

  • Versioned glossary with terms: Glossary.from_inputs(version, entries) — per glossary.py
  • Prompt terms: glossary.prompt_terms() included in translation prompt
  • Job service: get_or_create_glossary, lookup_glossary, remove_glossary — per job_service.py
  • GlossaryEntry: term, translation, case_sensitive, category (brand/legal/general)
  • UI: add entry, list entries, version display, prompt inclusion note

Side-by-Side Review — Full Workspace

  • Source (read-only with glossary highlight yellow) vs Target (editable textarea) — side-by-side
  • Segment list with status badges: pending/translated/reviewed/approved/rejected, quality flags, fingerprint FP
  • Quality flags: validate_translation(segments, glossary) → status, flags, review_required — per quality.py
  • Review state: REQUIRED if quality issues, else NOT_REQUIRED
  • Human approval: Approve (green) / Reject (red) buttons, review_required true when quality issues
  • FP display: source_fingerprint → target_fingerprint SHA256

Audit Chain — Immutable

  • TranslationJobRecord: id, tenant_id, source_lang, target_lang, glossary_version, status, created_at
  • GlossaryVersionRecord: version, entries[], fingerprint sha256_hex, created_at
  • TranslationSegmentRecord: segment_id, source_fingerprint, target_fingerprint, quality_status, review_state
  • Progress: total, done, failed | Attempt: retry logic — per persistence.py
  • Evidence: evidence_chain with payload_hash, previous_hash — immutable
  • Export: source-hash presentation/export via /api/translations/jobs export, audit package

Batch Controls

  • Batch: enqueue_translation, record_translation_result, retry_failed_segments — per job_service.py
  • Progress bar: total/done/failed, cost tracking note
  • Jobs: {jobs.length} loaded, Glossaries: {glossaries.length} loaded — real API
