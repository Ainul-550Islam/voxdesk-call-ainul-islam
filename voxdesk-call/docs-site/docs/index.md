# VoxDesk developer documentation

VoxDesk is a programmable voice-agent platform. This site is the integration
reference for teams building on the published API and deploying branded
customer experiences.

## Start here

- [Getting started](getting-started.md) — make your first authenticated API
  request and understand the public widget flow.
- [API reference](api/index.md) — request and response schemas generated from
  the FastAPI OpenAPI document.
- [Changelog](changelog.md) — product and API changes by release.

The generated API reference covers the buyer-facing contract. Internal API
families are deliberately not represented as stable integration surfaces.
